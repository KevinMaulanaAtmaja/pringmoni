## Debugging Protocol

### Phase 1: Reproduce
1. Understand expected vs actual behavior
2. Document reproduction steps

### Phase 2: Isolate
1. Narrow the scope - which component is failing?
2. Gather evidence - error messages, logs, git history
3. Form hypotheses

### Phase 3: Diagnose
1. Test hypotheses systematically
2. Trace the execution flow
3. Identify where expected and actual behavior diverge

### Phase 4: Fix
1. Implement minimal, targeted fix
2. Verify the fix works
3. Ensure no regressions

### Phase 5: Document
1. Root cause analysis
2. Prevention recommendations
